# Italian Gangs

Describes Italian gang members and their nationalities. No further
contextual data available. 1-Mode matrix 67x67 person by person,
relations are co-membership of gangs. Attribute data is gang member’s
country of origin, coded numerically. No codebook available.

## Usage

``` r
covert_24
```

## Format

igraph object
