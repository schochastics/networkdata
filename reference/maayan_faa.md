# FAA Preferred Routes

This network was constructed from the USA's FAA (Federal Aviation
Administration) National Flight Data Center (NFDC), Preferred Routes
Database. Nodes in this network represent airports or service centers
and links are created from strings of preferred routes recommended by
the NFDC.

## Usage

``` r
maayan_faa
```

## Format

igraph object

## Source

Data downloaded from http://konect.uni-koblenz.de/ orginaly from
http://research.mssm.edu/maayan/datasets/qualitative_networks.shtml
