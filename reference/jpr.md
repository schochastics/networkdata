# Joint Senate Press Releases

These data are from Justin Grimmer's doctoral dissertation in political
science at Harvard. They record instances of joint press releases issued
by U. S. Senators.

## Usage

``` r
jpr
```

## Format

igraph object

## Source

http://moreno.ss.uci.edu/data.html#jpr
