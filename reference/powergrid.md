# Powergrid

This undirected network contains information about the power grid of the
Western States of the United States of America. An edge represents a
power supply line. A node is either a generator, a transformator or a
substation.

## Usage

``` r
powergrid
```

## Format

igraph object

## Source

Data downloaded from http://konect.uni-koblenz.de/ orginaly from
http://toreopsahl.com/datasets/#uspowergrid
