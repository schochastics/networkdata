# Maayan Pdzbase

This is a network of protein–protein interactions from PDZBase.

## Usage

``` r
maayan_pdzbase
```

## Format

igraph object

## Source

Data downloaded from http://konect.uni-koblenz.de/ orginaly from
http://research.mssm.edu/maayan/datasets/qualitative_networks.shtml

## References

Jerome Kunegis. KONECT - The Koblenz Network Collection. In Proc. Int.
Web Observatory Workshop, pages 1343-1350, 2013.

Thijs Beuming, Lucy Skrabanek, Masha Y. Niv, Piali Mukherjee, and Harel
Weinstein. PDZBase: A protein–protein interaction database for
PDZ-domains. Bioinformatics, 21(6):827–828, 2005.
