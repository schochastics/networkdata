# Road network Europe

This is the international E-road network, a road network located mostly
in Europe. The network is undirected; nodes represent cities and an edge
between two nodes denotes that they are connected by an E-road.

## Usage

``` r
euroroad
```

## Format

igraph object

## Source

Data downloaded from http://konect.uni-koblenz.de/ orginaly from
http://lovro.lpt.fri.uni-lj.si/support.jsp
