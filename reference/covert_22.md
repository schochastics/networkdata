# Islamic State Allegiances

2-mode dataset describing groups allied to Islamic State and the
countries in which they are operating 2-mode matrix 47 x 20
organizations by state, undirected binary ties.

## Usage

``` r
covert_22
```

## Format

igraph object

## Source

Available from Manchester
(https://sites.google.com/site/ucinetsoftware/datasets/covert-networks)
