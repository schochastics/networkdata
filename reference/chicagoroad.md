# Road Transportation Network Chicago

This is the road transportation network of the Chicago region (USA).
Nodes are transport nodes, and edges are connections.

## Usage

``` r
chicagoroad
```

## Format

igraph object

## Source

Data downloaded from http://konect.uni-koblenz.de/ orginaly from
http://www.bgu.ac.il/~bargera/tntp/

## References
