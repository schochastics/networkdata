# Taro Exchange

These data represent the relation of gift-giving (taro exchange) among
22 households in a Papuan village. Hage & Harary (1983) used them to
illustrate a graph hamiltonian cycle. Schwimmer points out how these
ties function to define the appropriate persons to mediate the act of
asking for or receiving assistance among group members.

## Usage

``` r
taro
```

## Format

igraph object
