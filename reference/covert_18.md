# FIFA

Two Networks of Standing Committee membership. These are overt networks
with covert elements. 2-Mode persons to Standing Committees (converted
to 1-Mode) 340 x 340 persons by persons undirected binary 450 x 450
persons by persons undirected binary

## Usage

``` r
covert_18
```

## Format

list of igraph objects

## Source

Available from Manchester
(https://sites.google.com/site/ucinetsoftware/datasets/covert-networks).
Reconstructed by Gemma Edwards from Select Committee 2006 activity
report.
