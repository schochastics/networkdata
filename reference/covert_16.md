# Domestic Terrorist Web Links

Network of hyperlinks between domestic terrorist group websites in the
United States. DATA FORMATS: UCINET, .csv 1-mode matrix 32 x 32 website
by website Directed binary ties are based on analysis of hyperlinks
between sites.

## Usage

``` r
covert_16
```

## Format

igraph object

## Source

Available from Manchester
(https://sites.google.com/site/ucinetsoftware/datasets/covert-networks)
