# Linux Terrorists

These are two datasets about a set of terrorists and the attacks they
carry out collected by the MIND Lab at University of Maryland (UMD)
(http://www.mindswap.org/). NETWORK 1-mode matrix 645 x 645 organization
by organization, directed ties. Ties are co-location of terrorist
attacks. 1-mode matrix 260 x 260 organization by organization, directed
ties. Ties are co-located terrorist attacks by same organisation.

## Usage

``` r
covert_27
```

## Format

list of igraph objects

## Source

Available from Manchester
(https://sites.google.com/site/ucinetsoftware/datasets/covert-networks).
