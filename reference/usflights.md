# US Flights 2010

This is the directed network of flights between US airports in 2010.
Each edge represents a connection from one airport to another, and the
weight of an edge shows the number of flights on that connection in the
given direction, in 2010.

## Usage

``` r
usflights
```

## Format

igraph object

## Source

Data downloaded from http://konect.uni-koblenz.de/ orginaly from
http://toreopsahl.com/datasets/#usairports

## References

Jerome Kunegis. KONECT - The Koblenz Network Collection. In Proc. Int.
Web Observatory Workshop, pages 1343-1350, 2013.
