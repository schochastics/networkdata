# Les Miserables co-appearances

Weighted network of co-appearances of characters in Victor Hugo's novel
"Les Miserables". Nodes represent characters as indicated by the labels
and edges connect any pair of characters that appear in the same chapter
of the book. The values on the edges are the number of such
coappearances.

## Usage

``` r
miserables
```

## Format

igraph object

## Source

http://moreno.ss.uci.edu/data#lesmis
