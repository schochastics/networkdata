# Brunson Corporate Leadership

This bipartite network contains person–company leadership information
between companies and 20 corporate directors. The data was collected in
1962. Left nodes represent persons and right nodes represent companies.
An edge between a person and a company shows that the person had a
leadership position in that company.

## Usage

``` r
brunson_corporate_leadership
```

## Format

igraph object

## Source

Data downloaded from http://konect.uni-koblenz.de/ orginaly from
https://github.com/corybrunson/triadic
