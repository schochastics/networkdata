# Philippines Bombing

This is a time series that treat specific attacks as endpoints and
depict the evolution of relations between individuals indirectly and
directly associated with the Philippines bombing
http://en.wikipedia.org/wiki/Rizal_Day_bombings 1-mode stacked matrices
16 x 16 person by person nodes, data on 11 time periods plus kinship
data and tie extinguished data. Codebook available here
http://doitapps.jjay.cuny.edu/jjatt/files/Relations_Codebook_Public_Version2.pdf

## Usage

``` r
covert_37
```

## Format

list of igraph objects
