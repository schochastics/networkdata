# Collaboration in Jazz

The data here record a network of jazz bands. The data were obtained
from The Red Hot Jazz Archive digital database. The data include 198
bands that performed between 1912 and 1940, with most of the bands
performing in the 1920's. In this case each vertex corresponds to a
band, and a link between two bands is established if they had at least
one musician in common.

## Usage

``` r
jazz
```

## Format

igraph object

## Source

http://moreno.ss.uci.edu/data.html#jazz
