# Hens Pecking order

Records the "peck order" of a flock of 32 White Leghorn hens studied in
1946. A tie from hen a to b means that hen a can peck hen b. The author
claims that temporal changes are rare; once a hen dominates another,
that pattern persists.

## Usage

``` r
hens
```

## Format

igraph object

## Source

http://moreno.ss.uci.edu/data.html#hens

## References

Guhl, A. M., 1953. Social Behavior of the Domestic Fowl. Manhattan,
Kansas: Kansas State College, Agricultural Experiment Station, Technical
Bulletin 73.
