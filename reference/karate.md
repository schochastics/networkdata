# Karate Club (binary)

These are data collected from the members of a university karate club by
Wayne Zachary (presence or absence of ties among the members of the
club)

Zachary (1977) used these data and an information flow model of network
conflict resolution to explain the split-up of this group following
disputes among the members.

## Usage

``` r
karate
```

## Format

igraph object

## Source

http://moreno.ss.uci.edu/data#zachary

## References

Zachary W. (1977). An information flow model for conflict and fission in
small groups. *Journal of Anthropological Research*, 33, 452-473.
