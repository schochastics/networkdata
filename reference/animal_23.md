# Elephantseal Dominance (weighted)

Species: *Mirounga angustirostris*

Taxonomic class: Mammalia

Population type: free-ranging

Geographical location: California, USA

Data collection technique: survey scan

Interaction type: dominance

Definition of interaction: Dominance status determined by Elo rating
based on winner of an competitive interaction and intensity of
interaction

Edge weight type: frequency

Total duration of data collection: 69 days

Time resolution of data collection (within a day):

Time span of data collection (within a day): focal follow/ad libitum

Note: Network represent interactions collected over different years
and/or in different colonies
