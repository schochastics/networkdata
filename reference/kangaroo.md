# Kangaroo

Frequencies of observed physical proximities among a collection of 17
free-ranging grey kangaroos. Observations were made in the Nadgee Nature
Reserve in New South Wales. There were 18 kangaroos in the original
report, but one (number M11) was never observed and is therefore dropped
from this network.

Two kinds of dominance ranks are included. One, ss, is the ratio of an
animal's number of "successes" to its number of "involvements." The
other, ps, is calculated by assigning an animal 2 points for each other
animal it bests on more than 50\\

## Usage

``` r
kangaroo
```

## Format

igraph object
