# INSNA Teacher Student

When Barry Wellman founded the International Network for Social Network
Analysis (INSNA) in 1977, he sent a questionnaire to all the founding
members. Included were questions on who taught each founder and who each
founder taught. This data set is based on their responses.

## Usage

``` r
insna
```

## Format

igraph object

## Source

http://moreno.ss.uci.edu/data#ts
