# Ant Colony (I)

These are observations of ritual dominance activities in an ant
community (a collection of 16 female Leptothorax allardycei ants over
18.2 hours in a queenright colony)

## Usage

``` r
ants_1
```

## Format

igraph object

## Source

http://moreno.ss.uci.edu/data.html#ants

## References

B. J. Cole, 1981, "Dominance hierarchies in Leptothorax ants" *Science*,
212: 83-84.
