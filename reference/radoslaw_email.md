# Radoslaw - Email Network

This is the internal email communication network between employees of a
mid-sized manufacturing company. The network is directed and nodes
represent employees. The left node represents the sender and the right
node represents the recipient. Edges between two nodes are individual
emails.

## Usage

``` r
radoslaw_email
```

## Format

igraph object

## Source

Data downloaded from http://konect.uni-koblenz.de/ orginaly from
http://www.ii.pwr.wroc.pl/~michalski/index.php?content=datasets#manufacturing
