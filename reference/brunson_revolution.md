# Brunson Revolution

This bipartite network contains membership information of 136 people in
5 organisations dating back to the time before the American Revolution.
The list includes well-known people such as the American activist Paul
Revere. Left nodes represent persons and right nodes represent
organisations. An edge between a person and an organization shows that
the person was a member of the organisation.

## Usage

``` r
brunson_revolution
```

## Format

igraph object

## Source

Data downloaded from http://konect.uni-koblenz.de/ orginaly from
https://github.com/corybrunson/triadic
