# Brunson South Africa

This bipartite network contains person–company shared leadership
relations of "the five most representative companies" that are claimed
to represent "the small inner ring of South African Finance". Left nodes
represent persons and right nodes represent companies. An edge between a
person and a company shows that the person had a leadership position in
that company.

## Usage

``` r
brunson_south_africa
```

## Format

igraph object

## Source

Data downloaded from http://konect.uni-koblenz.de/ orginaly from
https://github.com/corybrunson/triadic
