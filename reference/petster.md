# Petster Friendships

This Network contains friendships between users of the website
hamsterster.com. The network contains many vertex attributes about the
pet.

## Usage

``` r
petster
```

## Format

igraph object

## Source

Data downloaded from http://konect.uni-koblenz.de/

## References

Jerome Kunegis. KONECT - The Koblenz Network Collection. In Proc. Int.
Web Observatory Workshop, pages 1343-1350, 2013.
